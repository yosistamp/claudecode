# skills開発

## 概要

AWSの設定内容のエビデンスを取得するSKILLSを開発する

## 指示内容
AIエージェントが下記処理を実行できるSKILLSファイルを作成する

1. 要件定義:
   - 取得リソース
     - VPC
     - サブネット
     - セキュリティグループ
       - inbound,outboudの一覧がわかる
    - VPCフローログ
    - AWS Config
      - 有効であること、利用リージョンすべて取れていること
    - CloudTrail
      - 有効であることの確認
     - s3
       - ライフサイクルポリシー
       - 暗号化
       - バックアップ
       - アクセスログ
    - ElasticIP
    - CloudFront
      - ログ出力設定
      - WAFアタッチ情報
    - LoadBalancer
      - ログ出力設定
      - WAFアタッチ情報
    - IAM
      - ユーザー
      - グループ
      - グループのユーザーへのアタッチ
      - ロール（ユーザーもしくはグループにアタッチしているもののみ）
      - ロールのグループ、ユーザーへのアタッチ
      - ポリシー（上記ロールに紐づくもののみ）
        - MFA設定、IP制限設定に関わるものはポリシー本体も出力
      - ポリシーのロールへのアタッチ 
    - EC2ノード
      - ノードで利用しているOS情報
2. 実現方法
  - AWS CLIを利用して情報を取得する
  - AWS CLIは導入済みの前提
  - aws login により認証済
3. 出力
  - マークダウン形式
  - 表形式で結果を出力
  - 結果はファイルに保存
    - リソース単位に別ファイルに出力
